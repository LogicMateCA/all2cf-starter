# 碰见问题记录

## 2026-09-04 — Mobile build route was not canonical

- `mobile-release.mjs` treated EAS as an automatic fallback when local tools were absent.
- Connected Mac builds used WSL `ssh` and a bare project script instead of the Logicmate Starter Windows host runner, dedicated keychain and headless Xcode wrapper.
- The generated project did not expose physical iPhone installation and cold-launch as a required evidence step.

Resolution: default iOS to the Starter plugin connected-Mac path, default Android to local Gradle, require explicit EAS selection, reject legacy `auto`, and require plugin-recorded device installation evidence before release handoff.

## 2026-09-05 — Android target detection ignored Windows

The WSL source script treated Android as unavailable because it inspected Linux only. The actual Windows SDK root is `C:\Users\alex\AppData\Local\Android`, with ADB and Microsoft JDK 21 available. Android now defaults to the Starter plugin Windows Host Runner and reads only centralized host references from `apps/super.env`.

## 2026-09-05 — Starter updates still depended on retired All2CF Channel

The maintenance script preferred `updateServiceUrl`, required a paid project token, and treated GitHub as forbidden even after Starter became independent. It now resolves immutable GitHub Releases directly and keeps all comparison, backup, conflict and verification work local.
