# 碰见问题记录

## 2026-09-04 — Mobile build route was not canonical

- `mobile-release.mjs` treated EAS as an automatic fallback when local tools were absent.
- Connected Mac builds used WSL `ssh` and a bare project script instead of the Logicmate Starter Windows host runner, dedicated keychain and headless Xcode wrapper.
- The generated project did not expose physical iPhone installation and cold-launch as a required evidence step.

Resolution: default iOS to the Starter plugin connected-Mac path, default Android to local Gradle, require explicit EAS selection, reject legacy `auto`, and require plugin-recorded device installation evidence before release handoff.
