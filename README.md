# All2CF Starter

Public community home for All2CF Starter, LogicMate's Cloudflare-native application foundation.

## Source status

**Open-source publication is planned.** The reusable Starter source and an explicit license have not been published yet. Until a `LICENSE` file is added, this repository is the public community and roadmap repository only.

The private All2CF control plane, account system, billing, deployment orchestration, managed credentials, and fleet operations are not part of the planned open-source distribution.

## Deployment

When the first source release is published, the same signed version will support:

1. manual deployment to the user's Cloudflare account;
2. Deploy to Cloudflare from the public repository;
3. one-click deployment from the All2CF Console.

The public deployment buttons will not be enabled until the repository contains standalone source, a license, and a verified release.

Learn more at [All2CF](https://all2cf.com).
