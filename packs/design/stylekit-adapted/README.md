# StyleKit-adapted Design Profiles

StyleKit commit `29141b684d5abb967558eb8083fbae91dbbc51b8` is a pinned design-research donor. Starter extracts useful structure, interaction, and hierarchy rules, then normalizes them through Product Design and Taste constraints.

Generated projects depend only on `design/catalog.json` and the deterministic Design Engine. They do not import StyleKit code, runtime APIs, Supabase, Next.js, registry behavior, brand identity, or automatic upstream updates.
