# Optional Growth Page Pack

This pack adds complete public growth families only when selected. A copied product must replace or remove the explicit noindex Starter samples, then add its own reviewed content, metadata, evidence, and configured destinations before release.

PowerAI supplied the audited route and content-collection pattern. Starter owns the resulting pages and does not track PowerAI after adaptation.

The pinned source inventory separates each family into index, detail, pagination where present, and its content collection:

- Blog: index, detail, pagination, `blog` collection.
- Case studies: index, detail, pagination, `case-studies` collection.
- Careers: index and detail, `careers` collection.
- Integrations: index and detail, `integrations` collection.

The pack owns an Astro 7 content configuration, schema-validating Markdown samples, index and detail routes for all four families, Blog and Case Study pagination, Blog RSS, availability/application gates, and the pinned `@astrojs/rss` dependency. A disposable all-families materialization generated and built 17 static routes with zero Astro diagnostics. Browser acceptance and project-specific truthful content remain separate verification gates.
